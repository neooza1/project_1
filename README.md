# Student Average Feedback Tool

A simple frontend web application that calculates a student’s average marks and returns basic feedback using JavaScript logic.

⸻

# Overview

This project allows users to enter subject marks, calculate an average score, and receive conditional feedback based on the result. It was built as a fundamentals project to practice core frontend development concepts and complete a full build-to-deployment cycle.

⸻

What This Project Demonstrates
	•	HTML form structure and input handling
	•	CSS layout, spacing, and basic responsiveness
	•	JavaScript DOM manipulation
	•	Conditional logic using if / else if / else
	•	Handling user input and displaying dynamic feedback
	•	Deploying a live project using Netlify
